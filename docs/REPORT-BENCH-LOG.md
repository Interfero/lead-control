# Замер отчёта §6.1

```bash
php artisan reports:bench-city-month
php artisan reports:bench-city-month --limit=80 --json
```

**Норматив ТЗ:** отчёт по городам, ≤80 городов, месяц — **≤ 3 с** полный ответ агрегатов.

Команда суммирует время `buildCityStats` по N активным городам за текущий месяц (аналог тела отчёта «по городу»).

Результаты фиксировать ниже.

| Дата | Среда | cities | total_ms | pass | Примечание |
|------|--------|--------|----------|------|------------|
| 2026-07-20 | prod shared | 48 | 333 | YES (≤3000) | активных городов 48, не 80 |
