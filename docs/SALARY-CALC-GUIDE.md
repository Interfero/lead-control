# Расчёт ЗП директоров — краткая инструкция

Раздел: **Касса → Расчёт ЗП** (`/crm/cfm/salary`).

## Для генерального директора

1. Откройте **Расчёт ЗП** — по умолчанию предыдущий месяц.
2. Таблица по городам: инкассация → ставка → доход → оклад → начислено → выплачено → доступно.
3. Клик по городу — детализация и история выплат.
4. **Настройки окладов** — включить/сумма/месяц начала. На старте: Нижний Новгород 50 000 ₽ с августа 2026.
5. Если статус «Требуется пересчёт» — укажите причину и нажмите **Пересчитать**.

## Для директора города

Видна только **своя** зарплата. Кнопка **Выплатить ЗП** открывает проводку «Зарплата Директора Филиала» с лимитом по доступному остатку. Текущий (незавершённый) месяц — только предварительный просмотр, без выплаты.

## Правила ставки

Материнские города:

| Сдано инкассации за месяц | Ставка на всю сумму |
|---|---|
| до 100 000 ₽ | 15% |
| 100 001–250 000 ₽ | 20% |
| от 250 001 ₽ | 25% |

**Города-спутники** (`parent_city_id`): отдельная ставка **10%** на всю сумму (пример: сдал 50 000 → доступно 5 000 при выключенном окладе).

Округление процента — half-up до целого рубля. База: проведённые операции **Инкассация** и **Инкас** за месяц (по `city_id` города, без слияния с матерью).

Связи спутников и города регионалов: `php artisan cities:sync-org-map`.

## Команды

```bash
php artisan salary:sync-month 2026-08
php artisan salary:sync-month 2026-08 --force
```
