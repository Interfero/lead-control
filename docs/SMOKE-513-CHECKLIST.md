# Smoke §5.13 — операционные инварианты

По ТЗ §12.A п.11. Регресс любого пункта = дефект приёмки.

**Дата прогона:** ___________  
**Среда:** prod / staging  
**Исполнитель:** ___________

| № | Инвариант | Как проверить | OK / FAIL | Комментарий |
|---|-----------|---------------|-----------|-------------|
| 1 | Спутник → 50/50 | Заказ в городе с `parent_city_id` (спутник): профильность «прочий» (50/50) по правилам; CFM согласован после правки | | |
| 2 | Дальний выезд | Галочку «дальний выезд» могут менять только `call_center` и `senior_dispatcher` | | |
| 3 | Поиск заказа | Поиск по ID / адресу / телефону находит заявку **вне** текущего архивного окна месяца, если задан явный критерий | | |
| 4 | Мобильная карточка | Длинное описание в textarea на iOS (Safari): читаемо, прокрутка в `readonly` (не «мёртвый» disabled) | | |
| 5 | Группировка городов | Спутники через `parent_city_id`; особый кейс «только Н. Новгород» не считается нормой навсегда | | |

**Итог:** ☐ все OK ☐ есть FAIL → завести дефект с датой
