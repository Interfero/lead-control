### 01.09 — СД, касса, Excel, сеть

- **Кнопка копирования для СД** в списке заказов (рядом с телефоном): ID, статус, телефон в E.164.
- **Остаток в отчёте по кассе:** формула «приход с заказов − общий расход»; по умолчанию только города с операциями; сброс периода на начало месяца; reload PHP-FPM (opcache отдавал старую формулу).
- **Excel сводки ДДС** (`report-cfm-summary.xlsx`): самописный XLSX заменён на **PhpSpreadsheet**; файл открывается в Excel на Windows без окна «Исправления».
- **Доступ через VPN / белые списки:** диагноз — A-запись Cloudflare в режиме DNS only. Решение: Proxied для `@`/`www`, без локальных bypass-скриптов. Док: `docs/NETWORK-UNIVERSAL-ACCESS.md`. Переключение в Cloudflare — за владельцем аккаунта.

### 02.09 — Единое окно (lead-desk)

Проблема: при первом заходе за день в Desk висели вчерашние заказы (кэш `orders_cache`).

Сделано:

- автосинхронизация при открытии списка (первый визит за день + если кэш старше 20 мин);
- полная синхронизация LC при первом заходе дня;
- cron: full sync LC каждые 15 мин;
- исправлен инкремент в `Crm1EloquentAdapter` (как в Desk API: открытые заказы всегда в выборке).

Настройки: `DESK_AUTO_SYNC_ON_VISIT`, `DESK_AUTO_SYNC_STALE_MINUTES`.
