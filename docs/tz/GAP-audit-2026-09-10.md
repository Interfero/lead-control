## Критичные противоречия ТЗ

1. Формула: код **30%**, ТЗ **40% computer** с 2026-09-09 MSK + `reward_rule`.
2. Уход с SP: код **скрывает** charge; ТЗ требует **сторно** невыплаченного.
3. Сверка: **limit N**, не cursor; charged/terminal часто пропускаются.
4. UI SP всё ещё дергает CRM (N+1).
5. Privacy: cookie remember email; **password в localStorage** на логине.
6. `TrustProxies=*`, session ~30 дней, нет security headers.
7. Нет outbox (LC) / inbox (SP) — при падении SP событие может потеряться до catch-up окна.
