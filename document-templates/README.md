# Шаблоны документов

Путь относительно корня проекта: `document-templates/`

- `docsofmasters/` — шаблоны документов для мастеров
- `docofilial/` — шаблоны документов для директоров и компании

Файлы из Word/PDF кладите в соответствующую папку. ИНН для подстановки хранится в карточке города (поле «ИНН» в разделе Управление → Города).
